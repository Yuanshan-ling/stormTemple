# 暴风神殿｜Unity 3D 场景原型

基于 Unity 制作的 3D 场景原型。项目围绕沙地、遗迹石材与神殿氛围进行场景搭建，并实现可自由浏览的镜头控制与基础环境呈现。

> **引擎版本：** Unity 6.3 LTS  
> **渲染管线：** URP 3D  
> **开发语言：** C#

## 项目内容

- 搭建以暴风神殿为主题的 3D 环境场景。
- 配置沙地、遗迹石材等场景材质，建立统一的地表与建筑视觉效果。
- 实现自由镜头控制，支持从不同角度观察场景。
- 使用 Unity 场景、材质与光照系统完成基础环境氛围表现。
- 通过 Editor 脚本设置项目首次打开时自动进入主场景，便于快速浏览项目。

## 打开项目

1. Clone 本仓库到本地。
2. 使用 Unity Hub 打开项目根目录。
3. 推荐使用 Unity 6.3 LTS 打开。
4. 项目首次打开时会自动尝试载入主场景。
5. 如未自动打开，请在 `Assets/Scenes/` 中手动打开：

   `stormTemple_Main.unity`

6. 在 Unity Editor 中点击 Play 运行并浏览场景。
